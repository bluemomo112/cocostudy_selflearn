# @cross/self-learn

Self-learning workspace module for Cross platform.

## Installation

```bash
npm install @cross/self-learn
```

## Usage

```tsx
import { SelfStudyWorkbench } from '@cross/self-learn';

function App() {
  return <SelfStudyWorkbench />;
}
```

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build
npm run build

# Type check
npm run typecheck
```

## Features

- 📚 Resource management
- ✍️ Note taking
- 📝 Task management
- 💬 AI chat integration
- 📊 Learning analytics
