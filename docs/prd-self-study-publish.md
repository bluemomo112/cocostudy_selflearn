# 自学空间发布逻辑（简版）

## 核心规则

- 教师首次发布时，将当前配置生成一份发布快照，学生创建学习空间时拉取一次；学生创建后不再自动拉取教师配置。
- 首次发布后，教师端外部按钮显示【重新发布】。
- 【保存草稿】只保存当前教师配置，不影响学生端当前已发布版本。
- 【取消】关闭发布弹窗，不保存本次编辑。
- 【取消发布】仅让学生端隐藏该自学内容，不删除已创建学生的学习数据。
- 【重新发布】采用覆盖逻辑，确认后更新学生端发布快照，并清除该自学内容对应的学生学习数据。
- 发布的时候默认带教师配置的agent，学习资源，学习任务。

## 交互流程

点击【重新发布】后打开发布弹窗，弹窗内提供【取消发布】、【保存草稿】、【取消】和【重新发布】。

重新发布按钮附近展示红色风险提示。教师点击【重新发布】后，先打开二次确认弹窗；只有点击【确认重新发布】后才真正覆盖配置并清除学生学习数据。

取消发布不触发重新发布确认，也不清除学生已有数据。取消发布后，教师再次操作发布仍需经过重新发布确认流程。
