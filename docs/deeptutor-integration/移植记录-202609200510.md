## 样式适配（P3 起要做）

- DeepTutor 用 **Tailwind v3**（`tailwind.config.js`），宿主 cross-new 是 **Tailwind v4**。
- 它的组件只读 `var(--background/--foreground/--card/--muted/--muted-foreground/--border/--primary/--primary-foreground)` 这 8 个最常用的令牌（另有 `--ring/--destructive/--accent/--popover/--secondary/--overlay`）。做法：给移植进来的组件套一个作用域类（如 `.dt-scope`），在里面把这些变量映射到 self-learn 自己的主题变量，不引入 DeepTutor 的四套主题，也不搬它整份 `globals.css`。
- 暗色：它靠 `<html class="dark">`，v4 默认是媒体查询，需要声明 `@custom-variant dark (&:where(.dark, .dark *))`，或把移植组件里的 `dark:` 改掉。
- **不要搬** `globals.css` 里 `@layer base` 的 `html, body { height:100%; overflow:hidden }` 和全局滚动条规则，会破坏宿主布局。
- 有少量直接写死的 Tailwind 调色板（`red-*`、`amber-*`、`emerald-*` 配 `dark:`），不随令牌变化，逐个决定要不要换。
